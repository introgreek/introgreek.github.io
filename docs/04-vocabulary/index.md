# Vocabulary

This tab contains the vocabulary lists that will be used in GREK 1111. Each unit of vocabulary covers the terms used up to any given exam (meaning that Exam 2 Vocabulary is expected to be used alongside Exam 1 Vocabulary, etc.), and the [complete vocabulary list](complete) contains all vocabulary words listed alphabetically. The [verb principal part list](verb-principal-parts) lists all verbs in the complete vocabulary with their principal parts.
