## Verbs

### Aspects of Conjugated Verbs

| Aspect | Options |
| -------- | -------- |
| person | 1st, 2nd, 3rd |
| number | singular, plural, dual |
| tense | aorist, present, imperfect, future, perfect, pluperfect, future perfect |
| voice | active, middle, passive |
| mood | indicative, imperative, subjunctive, optative |

### Verb Principal Parts

| Principal Part | Form of Verb | What You Can Conjugate With It |
| -------- | -------- | -------- |
| 1st | 1st sg. present | present and imperfect tense forms in all voices |
| 2nd | 1st sg. future | future active and middle forms |
| 3rd | 1st sg. aorist | aorist active and middle forms |
| 4th | 1st sg. perfect active | perfect, plupf., and fut. pf. active forms |
| 5th | 1st sg. perfect middle/passive | perfect, plupf., and fut. pf. middle/passive forms |
| 6th | 1st sg. aorist passive | aorist passive and future passive forms |

***

### (1st) Aorist Active Endings

| Person | Singular | Plural |
| ----- | ----- | ----- |
| 1st | `-α` | `-αμεν` |
| 2nd | `-ας` | `-ατε`|
| 3rd | **-ε(ν)** | **-αν** |

### (1st) Aorist Middle Endings

| Person | Singular | Plural |
| ----- | ----- | ----- |
| 1st | `-άμην` | `-άμεθα` |
| 2nd | `-ω` | `-ασθε`|
| 3rd | **-ατο** | **-αντο** |

### Sample 1st Aorist Active/Middle Conjugation
* Paradigm verb: κελεύω

| Voice | 3rd Singular | 3rd Plural |
| ----- | ----- | ----- |
| Active | ἐκέλευσε(ν) | ἐκέλευσαν |
| Middle | ἐκελεύσατο | ἐκελεύσαντο |

## Nouns

### Aspects of Declined Nouns

| Aspect | Options |
| -------- | -------- |
| gender | masculine, feminine, neuter |
| case | nominative, genitive, dative, accusative, vocative |
| number | singular, plural, dual |

### Noun Principal Parts

| Word Order in Entry | Function |
| -------- | -------- |
| 1st | nominative singular |
| 2nd | genitive singular |
| 3rd | gender |
| 4th | definition |
